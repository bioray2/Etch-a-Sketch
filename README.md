# Etch-a-Sketch
This is the 4th project in The Odin project.

The aim of this project is to build a grid based custom sized "Etch-A-Sketch" that tracks the users 
mouse on a page using CSS, Javascript and HTML.

Skills Demonstrated:

- The use of loops
- 2D Arrays using nested for loops
- Using JS to modify both CSS and HTML
- Blending Javascript CSS and HTML to make a function program
- Using Git for commits and version control
- Managing user input
